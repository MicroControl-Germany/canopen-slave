Cos453_InputStatus_s Struct Reference

Detailed Description

This structure mirrors the Input status object (6111h) as specified in CiA 453 section 9.5.20. It carries the five UNSIGNED32 status sub-parameters of the power supply input circuitry. Sub-indexes 01h (Condition) and 03h (Event) are read-only over SDO and are updated by the application via Cos453_SetInputStatus(). Sub-indexes 02h (Logic) and 04h (Fault state) are additionally writeable over SDO.
