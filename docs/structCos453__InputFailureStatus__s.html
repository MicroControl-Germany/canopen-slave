Cos453_InputFailureStatus_s Struct Reference

Detailed Description

This structure mirrors the Input failure status object (6112h) as specified in CiA 453 section 9.5.21. It carries the five UNSIGNED32 failure status sub-parameters of the power supply input circuitry. Sub-indexes 01h (Condition) and 03h (Event) are read-only over SDO and are updated by the application via Cos453_SetInputFailureStatus(). Sub-indexes 02h (Logic) and 04h (Fault state) are additionally writeable over SDO.
