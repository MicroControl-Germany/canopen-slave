Cos453_Bank_s Struct Reference

Detailed Description

This structure defines the Actual bank record (Complex data type 0080h) as specified in CiA 453 section 9.2.2. A bank groups all output parameters needed to operate at a specific work-point. Multiple banks allow preprogrammed operating-point transitions. The active bank is selected via the bank sub-parameter of the output command object (6200h).

Values for voltage, current, power, frequency, and time delay shall be given as configured in the SI unit and prefix object 6000h.
