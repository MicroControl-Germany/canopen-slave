Cos453_DeviceStatusDelay_s Struct Reference

Detailed Description

This structure mirrors the Device status delay time object (6013h) as specified in CiA 453 section 9.5.7. It holds one UNSIGNED32 delay time per status channel. Sub-indices 0Dh..10h (reserved and device-specific) are not mapped.

The delay time for each channel shall be given as configured in the SI unit and prefix object 6000h.
