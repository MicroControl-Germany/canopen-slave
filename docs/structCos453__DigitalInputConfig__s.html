Cos453_DigitalInputConfig_s Struct Reference

Detailed Description

This structure mirrors the Digital input configuration object (6031h) as specified in CiA 453 section 9.5.17. Each field holds the UNSIGNED32 configuration word for one digital input. The value encodes local event connections (bits 5..0), a reserved field (bits 29..6, all set to 1), and device-specific bits (bits 31..30).
