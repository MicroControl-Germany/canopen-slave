Detailed Description

The constants in this group define the valid range boundaries and sentinel values for analog and discrete parameters as specified in CiA 453 section 9.5.2.

Analog parameters (INTEGER and UNSIGNED data types) use four boundary and sentinel constants per data type:

Suffix Meaning
_MIN Minimum valid parameter value
_MAX Maximum valid parameter value
_INV Invalid parameter value (error indicator)
_VNA Value not available or not requested

After power-on the device shall initialise all measured analog values to the _VNA sentinel. On detection of an internal failure the affected parameters shall be set to the _INV sentinel. Analog command parameters are set to _VNA when the command is not requested.

Discrete status and command sub-parameters throughout the profile use the 2-bit encoding defined by COS_DS453_DT_DISCRETE_OFF, COS_DS453_DT_DISCRETE_ON, COS_DS453_DT_DISCRETE_INV, and COS_DS453_DT_DISCRETE_VNA.
