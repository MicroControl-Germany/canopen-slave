Cos453_OutputStatus_s Struct Reference

Detailed Description

This structure mirrors the Output N status object (6201h, 6211h, ..., 6271h) as specified in CiA 453 section 9.5.32. Every field is a 32-bit word whose bit layout follows Figure 26 of the specification.

The sub-indexes 02h (logic) and 04h (fault state) are bank-specific and may hold different values per active bank. The condition (01h), event (03h), and fault indication (05h) sub-indexes are read-only status signals provided by the application via Cos453_SetOutputStatus().
