Cos402_Common_s Struct Reference

Detailed Description

CiA 402 parameters common to all operation modes

The structure holds object dictionary values that are independent of the selected operation mode: the PDS FSA controlword/statusword, option codes, mode selection, and all profile position and general velocity/acceleration limit objects. It is initialised by Cos402_ParmInit().
