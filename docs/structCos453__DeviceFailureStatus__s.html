Cos453_DeviceFailureStatus_s Struct Reference

Detailed Description

This structure mirrors the Device failure status object (6012h) as specified in CiA 453 section 9.5.6. Every field is a 32-bit word whose bit layout follows Figure 14 of the specification.

The condition sub-parameter (01h) accumulates the failure states of the input and all outputs as well as device-specific signals. The logic, fault state, and fault indication sub-parameters configure and reflect the failure processing chain as defined in section 7.3.
